# Public API-credit plan

Any project API credits will be used only for the public open-source framework and synthetic, non-customer data.

## Planned work

1. Build and validate optional OpenAI Agents SDK reference adapters.
2. Expand the reproducible evaluation matrix for tool use, semantic drafts, evidence selection, trusted compilation, deterministic verification, human approval, restart patterns, exact-use authorization, and audit reconstruction.
3. Add adversarial cases for prompt injection, unsupported claims, evidence mismatch, cross-scope access, disclosure violations, approval bypass, replay, and record tampering.
4. Use Codex CLI for public contributor workflows, tests, issue-to-fix development, documentation, migrations, and safe refactoring.
5. Publish sanitized compatibility findings, fixtures, benchmark summaries, and CI recipes.

## Initial milestones

- stable v0.1 release;
- at least 100 synthetic evaluation cases;
- Python reference package;
- optional OpenAI Agents SDK example;
- documented Codex contributor workflow;
- public threat model;
- reproducible CI validation and compatibility reports.

## Excluded uses

Credits will not be used for customer workloads, private data, proprietary DigiTrust SaaS functionality, commercial integrations, or production operations.
